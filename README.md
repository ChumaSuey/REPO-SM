# R.E.P.O Save Manager

A simple yet powerful tool to manage your *R.E.P.O* game saves on Windows, macOS, and Linux (including Steam Deck).

## Quick Start

```bash
pip install -r requirements.txt
python main.py
```

## Features

- Backup and restore game saves with one click
- Safe restore with automatic rollback on failure
- In-app Recycle Bin for soft-deletes
- Rename, toggle, and organize backups
- Context menus, keyboard shortcuts (`F5`, `Delete`)
- Cross-platform save path detection (Windows, macOS, Linux native + Proton)
- Dark-themed, HiDPI-aware GUI
